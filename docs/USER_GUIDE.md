# 使用指南

> 适用版本：v1.2.0（资源树 + 多 Tab + 内联编辑）。
> 安装步骤见 [GETTING_STARTED.md](GETTING_STARTED.md)，接口见 [API.md](API.md)。

---

## 1. 界面总览

```
┌ TopBar：品牌 / 设置 / 帮助 ────────────────────────────────────────┐
├ 资源树（连接 → 数据库 → 表）┬ 多 Tab 工作区（表 / SQL 查询）      ┤
│                             │                                     │
│  - 刷新 / 设置入口           │  - Tab 栏：＋新建查询、×关闭         │
│  - 单击表打开 / 双击看数据   │  - 内容区：数据 / 结构 / 信息        │
│                             │                                     │
├ 状态栏：当前连接 / 类型 / 连通状态 / 路径 / 数据目录提示 ──────────┤
└───────────────────────────────────────────────────────────────────┘
```

- **设置**：连接管理（新增/编辑/测试/删除）、清空本地工作区状态；
- **帮助**：欢迎页（使用引导、最近连接、快捷键说明）；
- **状态栏**：当前连接、数据库类型、连接状态、当前表路径。

---

## 2. 连接管理（设置页）

右上角「设置」进入连接管理：

| 操作 | 说明 |
|---|---|
| 新建连接 | 名称、类型（MySQL / PostgreSQL）、主机、端口、用户名、密码、字符集、是否启用 |
| 编辑 | 密码留空表示不修改；保存后会回收旧连接池，下次访问使用新配置 |
| 测试 | 立即测试连通性并刷新连接状态 |
| 删除 | 删除连接配置与连接池，并关闭该连接对应的工作区 Tab |
| 清空本地工作区状态 | 仅清空 Tab/展开状态/上次选择等前端状态，不影响连接配置 |

> **PostgreSQL**：当前仅支持新增/编辑/测试连接；库表浏览与查询能力开发中（MySQL 不受影响）。

---

## 3. 资源树

- 层级：**连接 → 数据库 → 数据表**；
- 展开时才加载下级数据（懒加载），节点错误可点击重试；
- 顶部按钮：刷新连接与已展开节点、跳转设置；
- 表节点显示表注释（若数据库提供）；
- **单击**表：打开/聚焦该表的 Tab（保持上次的数据/结构/信息子页）；
- **双击**表：打开并强制切到「数据」子页；
- 无主键表的 Tab 仍可浏览，但数据页会显示只读提示。

---

## 4. 多 Tab 工作区

- 同时打开**多张表**和**多个 SQL 查询**，最多 12 个 Tab；
- 点击 Tab 切换，`×` 关闭当前 Tab，`＋` 新建查询；
- 查询 Tab 有未执行 SQL 草稿时，关闭会二次确认；
- **刷新页面后恢复**：Tab 列表、激活 Tab、资源树展开节点、上次连接/库/表、每页条数、SQL 草稿；
- 失效连接（被删除）对应的 Tab 会在启动时自动清理并提示。

---

## 5. 表工作区

顶部上下文栏显示：连接 › 数据库 › 表名 · 类型 · 列数/行数，并提供「刷新」「更多 ▾」。

### 5.1 数据页

| 功能 | 说明 |
|---|---|
| 服务端分页 | 每页 20/50/100/200 可选，分页条固定在底部；`共 N 条` 来自服务端 `COUNT(*)` |
| 全局行号 | 第 2 页从 21 开始连续编号 |
| 刷新 | 重新拉取当前页数据（含行数） |
| 新增行 | 弹窗按列填写，必填列校验；成功后刷新 |
| 删除行 | 按主键定位删除（无主键表不可删除单行） |
| 双击编辑 | 见 5.2 |

### 5.2 单元格内联编辑

- **双击单元格**进入编辑，Enter 或失焦保存，`Esc` 取消；值未变化时静默退出；
- 编辑器按列类型：
  - 文本/数字 → 输入框；
  - `DATE` → 日期选择器；`DATETIME/TIMESTAMP` → 日期时间选择器；
  - `BOOLEAN/BOOL` → 下拉 true/false；
- 保存走服务端参数化更新，并携带旧值做**乐观冲突检测**：
  - 该行/该列在页面加载后被别人（或你的 SQL Tab）改过 → 提示「该行已被其他操作修改，已为你刷新最新数据」；
  - 行已被删除 → 提示并刷新；
- 不可编辑的情况（单元格只读并显示原因 tooltip）：
  - 行标识列（主键 / `UNIQUE NOT NULL` 索引列）、自增列；
  - `BLOB/BINARY/BIT/JSON/空间类型`；
  - 整个表没有行标识列 → 顶部显示只读横幅（建议为表添加主键）；
  - 配置关闭内联编辑（`minicat.ui.inline-edit-enabled=false`）。
- 清空输入表示写入 SQL `NULL`；必填列（`NOT NULL`）不允许清空。

### 5.3 结构页

展示：列名、数据类型、可空、键（`PK` 主键 / `UK` 唯一非空索引=行标识）、默认值、自增、注释。

### 5.4 信息页

展示：连接、数据库类型、库名、表名、列数、行数、当前页码、每页条数。

### 5.5 「更多 ▾」菜单

| 操作 | 说明 |
|---|---|
| 新建表 | 可视化定义列（名称/类型/长度/可空/主键/自增/默认值/注释） |
| 导入数据 | CSV（`.csv`）或 Excel（`.xlsx/.xls`），≤50MB；表头必须与表的所有列名完全一致；失败整体回滚；成功后自动切到数据页并跳到最后一页 |
| 自定义 SQL | 针对当前连接/库执行任意 SQL；危险语句二次确认，结果在弹窗中展示 |
| 删除表 | 二次确认后删除，关闭当前 Tab 并刷新资源树 |

## 6. SQL 工作台（查询 Tab）

- 顶部选择连接与数据库（默认继承打开查询时的上下文）；
- 编辑器支持 `Ctrl+Enter` 执行、格式化、清空；
- `SELECT` 走查询接口，其余语句（INSERT/UPDATE/DELETE/DROP TABLE）走更新接口；
- `DELETE/DROP/TRUNCATE` 等危险语句会二次确认；
- 结果区：查询显示表格 + 行数/耗时；更新显示影响行数；
- SQL 草稿随 Tab 保存，刷新页面不丢失；
- 查询结果一次性加载，**大表请自行加 `LIMIT`**。

## 8. 快捷键

| 快捷键 | 行为 |
|---|---|
| `Alt+T` | 新建查询 Tab |
| `Alt+W` | 关闭当前 Tab |
| `Ctrl+Enter` | 在查询 Tab 执行 SQL |
| `Enter` / 失焦 | 保存正在编辑的单元格 |
| `Esc` | 取消单元格编辑 / 关闭弹窗 |

> 浏览器保留的 `Ctrl+T` / `Ctrl+W` / `Ctrl+Tab` 无法被页面拦截，因此使用 `Alt` 组合。

## 10. 使用注意事项

1. **内联编辑直接影响目标库数据**，没有撤销；重要数据请先备份或使用只读账号；
2. 导入要求表头与表列完全一致（含自增列），不支持列子集映射；
3. 「行数」来自 `COUNT(*)`，超大表刷新/翻页会较慢；
4. 无主键/唯一非空索引的表无法安全编辑单行，会显示只读；
5. 共享/生产环境建议：关闭内联编辑、使用最小权限数据库账号，并阅读 [SECURITY.md](../SECURITY.md)；
6. 页面数据是加载时的快照，长时间停留后请先刷新再修改。
