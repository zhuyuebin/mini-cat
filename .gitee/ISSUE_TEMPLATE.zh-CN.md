# MiniCat 项目介绍

## 项目简介

MiniCat 是一个基于 Web 的轻量级数据库管理工具,提供直观的图形界面来管理多种数据库。

### 核心功能

- ✅ 数据库连接管理
- ✅ SQL查询执行
- ✅ 数据浏览和展示
- ✅ 连接池监控
- ✅ 安全防护(SQL注入防护、密码加密)

### 技术特点

- 🚀 前后端分离架构
- 🎨 现代化UI设计
- 🔐 企业级安全标准
- ⚡ 高性能连接池
- 🐳 容器化部署支持

---

## 软件架构

### 后端技术
- Spring Boot 3.5
- Spring Security
- Spring Data JPA
- HikariCP
- H2 Database

### 前端技术
- Vue 3.5
- Vite
- Element Plus
- Pinia
- Vue Router

## 安装教程

### 环境要求

- JDK 17+
- Maven 3.6+
- Node.js 20+(仅开发需要)

### 快速启动

```bash
# 克隆项目
git clone https://gitee.com/your-username/MiniCat.git

# 进入目录
cd MiniCat

# 启动应用
./start.sh  # Linux/Mac
# 或
start.bat   # Windows
```

详细部署说明请参考 [DEPLOYMENT.md](DEPLOYMENT.md)
