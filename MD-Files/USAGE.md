## 快速开始

### 1. 启动应用

选择以下任一方式启动:

```bash
# 方式1: 使用脚本
./start.sh  # Linux/Mac
start.bat   # Windows

# 方式2: 使用Docker
docker-compose up -d

# 方式3: 手动运行
java -jar target/minicat-server-0.0.1-SNAPSHOT.jar
```

### 2. 访问应用

打开浏览器访问: **http://localhost:8080**

## 数据库连接管理

### 添加新连接

1. 点击左侧导航栏的 "连接管理"
2. 点击 "新建连接" 按钮
3. 填写连接信息:
   - **连接名称**: 自定义名称(如: My MySQL)
   - **数据库类型**: MySQL / PostgreSQL / H2
   - **主机**: 数据库服务器地址(如: localhost)
   - **端口**: 数据库端口(如: 3306)
   - **用户名**: 数据库用户名
   - **密码**: 数据库密码
   - **数据库名**: 要连接的数据库(可选)
4. 点击 "测试连接" 验证配置
5. 点击 "保存" 完成添加

### 编辑连接

1. 在连接列表中找到目标连接
2. 点击 "编辑" 按钮
3. 修改连接信息
4. 点击 "保存"

### 删除连接

1. 在连接列表中找到目标连接
2. 点击 "删除" 按钮
3. 确认删除操作

⚠️ **注意**: 删除连接不会删除实际的数据库,只是移除MiniCat中的连接配置。

## SQL查询

### 执行查询

1. 选择一个数据库连接
2. 进入 "SQL查询" 页面
3. 在编辑器中输入SQL语句
4. 点击 "执行" 按钮或按 `Ctrl+Enter`

### 示例查询

```sql
-- 查询所有表
SHOW TABLES;

-- 查询数据
SELECT * FROM users LIMIT 100;

-- 统计查询
SELECT COUNT(*) as total FROM orders;

-- 复杂查询
SELECT u.name, COUNT(o.id) as order_count
FROM users u
LEFT JOIN orders o ON u.id = o.user_id
GROUP BY u.name
ORDER BY order_count DESC;
```

### SQL格式化

点击 "格式化" 按钮可以自动格式化SQL语句,提高可读性。

### 查询结果

- 结果以表格形式展示
- 支持排序和分页
- 可以复制单元格内容
- 显示查询执行时间

## 常见问题

### Q1: 如何连接到远程数据库?

**A**: 确保:
1. 远程数据库允许外部连接
2. 防火墙开放了对应端口
3. 数据库用户有远程访问权限
4. 在MiniCat中正确配置主机地址和端口

### Q2: 忘记密码怎么办?

**A**: MiniCat只存储加密后的连接密码,无法找回。如果忘记数据库密码,需要:
1. 联系数据库管理员重置密码
2. 在MiniCat中更新连接配置

### Q3: 支持哪些数据库版本?

**A**: 
- MySQL 5.7+
- PostgreSQL 12+
- H2 2.x

### Q4: 如何备份连接配置?

**A**: 连接配置存储在H2数据库中,文件位于 `data/` 目录。备份该目录即可。

### Q5: 查询很慢怎么办?

**A**: 
1. 检查SQL语句是否有优化空间
2. 添加适当的索引
3. 限制查询结果数量(LIMIT)
4. 避免 SELECT *,只查询需要的字段

### Q6: 可以同时连接多个数据库吗?

**A**: 可以!MiniCat支持同时管理多个数据库连接,可以在不同连接间快速切换。

### Q7: 数据安全吗?

**A**: MiniCat采用多重安全措施:
- ✅ 密码加密存储
- ✅ SQL注入防护
- ✅ 参数化查询
- ✅ HTTPS支持(需配置)

## 最佳实践

### 1. 连接管理

- 使用有意义的连接名称
- 定期清理不再使用的连接
- 不要在生产环境使用root/admin账户

### 2. SQL编写

- 使用参数化查询防止SQL注入
- 避免在大表上执行全表扫描
- 使用 EXPLAIN 分析查询性能
- 重要操作前先备份数据

### 3. 性能优化

- 合理设置连接池大小
- 避免长时间持有数据库连接
- 定期清理日志文件
- 监控连接池使用情况

### 4. 安全建议

- 使用强密码
- 定期更换密码
- 启用HTTPS
- 限制访问IP
- 定期更新MiniCat版本
